# 개발 순서

> 무엇을 만들지는 [결정사항.md](결정사항.md), 세부 수치와 목록은 [세부설정.md](세부설정.md), 필요한 그림은 [도트_요구사항.md](도트_요구사항.md)에 있다.
> 원칙: **1장에서 연필잡이 하나로 모든 시스템을 먼저 완성**하고, 그다음 장과 직업을 늘린다.
> 기능 하나가 테스트를 통과하면 바로 커밋한다. 푸시는 말할 때만.

## 지금까지 된 것

- [x] 이동, 회피, 공격, 대화, 연필 모드, 저장
- [x] 1장 튜토리얼 (프롤로그, 다리 그리기, 문 닦기, 페이지 넘김)
- [x] 몬스터 6종 × 두 모습, 경험치와 레벨, 재료 드롭, 가방 화면
- [x] 내 마을 (빈 모눈종이, 바닥 칠하기, 자유 낙서), 포탈로 맵 이동
- [x] 1번: 수치 식(HP·MP·공격력·방어·치명타), 99레벨 경험치 곡선, 능력치 배분 화면(C), 피해 숫자
- [x] 그림: 1장 배경 5장, 내 마을 바닥 질감·포탈·건물 8개·소품 20개, 스킬 아이콘 (ChatGPT로 생성, `tools/map_v6_post.py` → `tools/import_map_v6.py`). 내 마을에 질감과 포탈 그림 적용
- [x] 6번: 1장 넓히기. 마을 + 사냥터 4장(들판, 갈림길, 모눈 숲, 지워진 길)을 문으로 잇기, 지도(M)
- [x] 2번: 기본 공격 3연타, MP 소모, 연필잡이 스킬 8종(쓰는 스킬 6, 지속 2), 스킬 창(K), Q·E·R 칸. 필살기(밑그림)는 아직 없음
- [x] 3번: 장비 6부위 × 모양 10 × 등급 5, 무작위 옵션, 몬스터 드롭, 가방 창(I)에서 입기·벗기·분해. 가방 칸 늘리기(24칸에서 6칸씩 60칸까지, 동전 또는 지우개 가루, 값은 두 배씩)
- [x] 4번: 동전, 문방구 할아버지(1장 마을)의 사기·팔기·만들기·강화, 소모품(1·2번 키). 만들기는 직접 그려서 만든다: 내 그림이 도트 아이콘이 되고, 견본과 비슷할수록 좋다 (장비 기본 능력 최대 +20%, 소모품 2개). OpenAI 키를 넣으면 AI가 도트로 다시 그려 준다 (scripts/ai_pixel.gd)
- [x] 필살기 "밑그림"(V 키, 필력 5): 게이지, 컷인 일러스트, 점선 별 따라 그리기. 스킬 효과와 창 부품을 도트 그림으로 바꿈 (docs/도트_프롬프트_ui_v7.md)
- [x] 글자를 한글 도트 글꼴(Galmuri11)로
- [x] 5번: 쓰러진 몬스터를 도화지에 다시 그려 친구로(F, 따라 그리기 정확도에 따라 확률), 같이 다니는 친구(스스로 공격, G 키 스킬, 경험치 30%), 친구 창(P), 합치기(같은 종 별, 다른 종 섞기 3가지). 친구 우리 건물은 아직 없고 어디서나 P 로 연다. 말랑이 장면은 스토리 때 넣는다
- [x] 7번: 내 마을 2×2장에서 시작해 종이를 붙여 4×4장까지, 짓기 창(N)으로 건물 8종과 소품 20종 놓기·치우기. 건물은 점선을 따라 그려 짓고 85% 이상이면 정성 건물. 쓸 수 있는 건물은 내 집(잠자기), 문방구, 조합대
- [x] 8번: 쓰러지면 연필심 10%를 잃고 내 마을로, 하루 90분(낮 60 · 밤 30)과 밤의 어두운 화면, 피로도(사냥터 화면마다 2, 아침 6시나 잠자기로 회복)
