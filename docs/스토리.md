# 스토리

> 분위기: 따뜻하고 귀여운 모험. 주인공은 독백을 한다. 악당은 지우개 괴물.

## 한 줄 줄거리

어릴 때 그리다 만 공책을 다시 펼쳤더니, 지우개 괴물이 세계를 지우고 다니고 있었다.
주인공은 연필로 다시 그려 넣으며 괴물을 쫓아 마지막 페이지까지 간다.

## 등장인물

| 이름 | 설명 |
|---|---|
| **나 (그린이)** | 이 공책을 그린 아이. 공책 속에서는 "그린이"라고 불린다. 손에 연필을 들고 있다. |
| **하루** | 주인공이 공책에 맨 처음 그린 친구. 주인공을 알아보고 길잡이가 된다. |
| **낙서 슬라임** | 지우다 남은 자국에서 생긴 낙서. 연필심을 갖고 있다. 하루에게 이야기를 듣기 전에는 먼저 덤비지 않는다. |
| **지우개 괴물** | 마을을 지우고 다니는 장난꾸러기. 지워 놓은 걸 다시 그리는 주인공을 재밌어한다. |

## 설정

- **빨간 문:** 다음 페이지로 넘어가는 문. 페이지마다 하나씩 있다.
- **지우개 자국:** 괴물이 지나간 흔적. 뿌옇게 덮여 있고, 지우개로 문지르면 닦인다.
- **지우개 가루:** 괴물이 방금 있던 자리에 남는다.

## 1페이지: 공책 마을 (튜토리얼)

| 순서 | 장면 | 배우는 것 |
|---|---|---|
| 1 | 책상 위 공책을 펼치자 그림이 움직이고, 공책 속 마을로 들어간다. 독백 | 세계관 |
| 2 | 하루가 주인공을 알아본다. 다리가 지워졌다고 알려 준다 | 이동, 대화 |
| 3 | 풀밭의 슬라임을 잡아 연필심 3개를 모은다 | 공격, 회피 |
| 4 | 강가에서 점선을 따라 다리를 그린다 | 연필 |
| 5 | 다리 건너 빨간 문이 지우개 자국으로 뿌옇다. 문질러 닦는다 | 지우개 |
| 6 | 문이 열리자 지우개 괴물이 잠깐 나타나 다음 페이지로 도망간다 | 악당 소개 |
| 7 | 문으로 들어가면 페이지가 넘어간다 | 다음 페이지 예고 |

대사는 `scripts/npc.gd`(하루)와 `scripts/tutorial.gd`(독백, 괴물)에 있다.

## 앞으로 정할 것

- 2페이지의 장소와 새로 배우는 것 (건물 덧그리기, 무기 강화 등)
- 지우개 괴물이 지우는 이유
- 전체 페이지 수와 결말
