# 결정 사항

> 다른 문서와 어긋나면 **이 문서가 우선**이다. 맨 아래 "고쳐야 할 문서"에 적힌 곳은 아직 옛 내용이다.
> 2026-11-22 질문지(57문항)로 정함.

## 1. 방향

| 항목 | 결정 |
|---|---|
| 목표 | 내가 해 보고, 다른 사람들도 해 보게 한다 |
| 완성 범위 | 9장 전부 |
| 플랫폼 | PC + 모바일. PC를 먼저 완성하고 모바일은 그 뒤에 맞춘다 |
| 모바일 조작 | 가상 패드 + 손가락 그리기 |
| 큰 틀 | 메인 스토리(9장)는 메인 퀘스트, 나머지는 자유 모드 |
| 만드는 순서 | **1장에서 모든 시스템을 먼저 완성**(직업 1개), 그다음 직업과 장을 늘린다 |
| 제목 | 나중에 정함 ("공책 RPG"는 가제) |
| 언어 | 한국어. 대사와 이름을 표로 분리해 번역할 수 있는 구조로 |
| 유료 결제 | 나중에 정함 |

## 2. 캐릭터와 직업

| 항목 | 결정 |
|---|---|
| 직업 | **4직업**: 연필잡이, 붓잡이, 펜잡이, 지우개잡이 |
| 지우개잡이 | **스토리를 끝내야 열린다** (처음에는 3직업) |
| 전직 | **2번** (30레벨, 60레벨) |
| 직업 변경 | 못 바꾼다. 캐릭터를 새로 만든다 |
| 캐릭터 칸 | **8개** |
| 주인공 | **직업마다 다른 주인공** (겉모습과 성격이 다르다) |
| 이야기 | **주인공마다 다른 이야기** (하루와의 관계와 결말이 다르다) |
| 공유 | 내 마을, 창고, 도감은 모든 캐릭터가 같이 쓴다 |
| 스토리 건너뛰기 | 한 번 깬 장은 다른 캐릭터로 건너뛸 수 있다 |
| 레벨 상한 | 99 (스토리는 20 근처에서 끝난다) |
| 능력치 | 레벨마다 직접 배분 (필압, 끈기, 손끝, 눈썰미). 초기화는 아이템으로 |

## 3. 전투

| 항목 | 결정 |
|---|---|
| 기본 공격 | 3연타 |
| 스킬 | 스킬 트리 + MP |
| 전투 중 그리기 | 필살기와 포획에만. 평소 전투는 버튼만 |
| 보스 | 장마다 중간 보스 1 + 대장 1, **필드 보스도 있다** |
| 구조 | **혼자 하는 구조로 먼저 만들고, 온라인은 나중에 전투를 다시 짠다** |

## 4. 친구 (포획)

| 항목 | 결정 |
|---|---|
| 포획 | **몬스터 전부 포획 가능** (쓰러뜨린 뒤 다시 그려 준다) |
| 포획 조건 | **포획 도구(소모품)가 필요하다** |
| 동행 | 1명. 친구도 레벨이 오른다 |
| 합치기 | **둘 다**: 같은 종끼리 합치면 강화, 정해진 조합은 새 종이 된다 |

## 5. 장비와 경제

| 항목 | 결정 |
|---|---|
| 장비 획득 | 드롭 + 조합 |
| 등급 | 5등급(낙서, 스케치, 색칠, 덧칠, 완성) + 세트 + **유일 장비**(보스 전용) |
| 옵션 | 무작위 옵션 |
| 강화 | +7부터 실패 시 단계 하락, **+10부터 실패 시 파괴**. 보호 아이템으로 막을 수 있다 |
| 착용 제한 | 레벨 제한 + 무기만 직업 제한 |
| 겉모습 | 캐릭터에 보이는 것은 무기, 모자, 옷 세 부위 |
| 돈 | 동전(상점) + 연필심(그리기, 강화) |
| 가방 | 전부 칸 제한 (장비·소비·재료 탭마다 칸이 있고 늘려 간다) |
| 상점 | 문방구, 떠돌이 장터, 스티커 뽑기 |
| 처분 | 팔기와 장비 분해 |

## 6. 사냥터와 반복 콘텐츠

| 항목 | 결정 |
|---|---|
| 맵 | 내 마을의 포탈로 각 장에 들어간다. 장별 맵은 화면 여러 장을 문으로 잇는다 |
| 난이도 단계 | **4단계**: 흐릿한, 지워지는, 찢어진, 빈. 단계마다 권장 레벨 +20쯤 |
| 새 맵 | 스토리 뒤에 열리는 새 사냥터도 그림이 되는 대로 더한다 |
| 8장 | 스토리 뒤에는 **사냥터로 다시 간다** |
| 피로도 | 평소에는 있다. **게임 속 하루마다 가득** 찬다. **스토리를 끝내면 무제한** |
| 쓰러졌을 때 | 내 마을에서 깨어나고 연필심의 10%를 잃는다 |
| 시간 | 게임 속 낮밤, 하루가 약 1시간 30분 |
| 반복 콘텐츠 | 게시판 반복 퀘스트, 끝없는 탑, 도감, 보스 다시 도전 |

## 7. 내 마을과 생활

| 항목 | 결정 |
|---|---|
| 내 마을 | 플레이어가 직접 그리는 빈 모눈종이. **1장을 깬 뒤** 열린다 |
| 크기 | **화면 4장으로 시작해, 재료를 들여 16장까지 넓힌다** |
| 기본 시설 | 내 집, 문방구, 조합대, 창고, 게시판, 낚시터, 밭 |
| 추가 시설 | 강화소, 친구 우리, 식당, 박물관 |
| 생활 | 집·건물 짓기, 낚시, 채집과 요리, 집 안 꾸미기, 농사 |
| 주민 | 20명 이상, 호감도 있음 |
| 주민 출처 | **둘 다**: 이야기가 있는 주민(장마다 2~3명) + 직접 그려 만드는 주민 |

## 8. 이야기

| 항목 | 결정 |
|---|---|
| 분위기 | **지금보다 더 어둡게** (주민이나 친구가 이야기 중에 더 지워진다) |
| 결말 | 셋 이상 |
| 결말 기준 | **둘 다**: 없앤 수·다시 그린 수 + 결정적 장면의 선택지 |
| 결말 이후 | 계속 플레이. 말랑이는 돌아오지 않는다 |
| 대사 | 짧게, 전부 건너뛸 수 있게. 서브 퀘스트는 장마다 3~4개 |

## 9. 화면, 소리, 저장

| 항목 | 결정 |
|---|---|
| 편의 기능 | 시작 화면과 캐릭터 선택, 설정 화면, 지도, 공유 창고 |
| 저장 | 자동 저장 + 수동 저장. 지금은 내 컴퓨터에, 온라인을 넣을 때 서버로 옮긴다 |
| 소리 | AI로 생성 (도구와 이용 조건은 직접 확인) |

## 12. 주의할 점 (결정에서 따라 나오는 것)

| # | 내용 |
|---|---|
| 1 | **수동 저장 + 깨지는 강화:** 강화 전에 저장해 두고 실패하면 불러오는 것이 가능하다. 혼자 하는 동안은 허용하고, 서버 저장으로 옮길 때 막는다 |
| 2 | **주인공마다 다른 이야기:** 스토리, 프롤로그 컷, 초상화, 걷기·공격 도트가 4벌 필요하다. 지금 쓴 스토리는 연필잡이의 이야기가 된다 |
| 3 | **온라인 같이 사냥:** 전투를 서버 기준으로 다시 만들어야 한다. 그때 지금 전투 코드의 상당 부분을 새로 쓴다 |
| 4 | **더 어둡게 + 생활 요소:** 마을을 꾸미는 따뜻한 부분과 잃는 이야기가 같이 간다. 내 마을로 이사 온 주민은 지워지지 않게 해야 마을이 안전한 곳으로 남는다 |
| 5 | **분량:** 처음 계획(4시간짜리 혼자 하는 RPG)의 여러 배다. 1장에서 연필잡이 하나로 모든 시스템을 먼저 돌린다 |

## 15. 만드는 순서 (1장에서 전부)

1. 1장 넓히기 (화면 5장 잇기) — 배경 그림 필요
2. 능력치 배분, MP, 3연타, 스킬 트리 (연필잡이)
3. 장비: 드롭, 무작위 옵션, 착용, 겉모습 3부위, 가방 칸
4. 동전과 상점, 조합, 강화와 분해
5. 포획과 친구 동행, 합치기
6. 내 마을: 건물 짓기, 소품, 넓히기, 쓰러지면 마을로
7. 낮밤과 피로도
8. 낚시, 채집, 요리, 농사, 집 안 꾸미기
9. 주민 이사와 호감도, 서브 퀘스트, 게시판
10. 중간 보스, 대장, 필드 보스, 난이도 단계
11. 시작 화면, 캐릭터 선택, 설정, 지도, 소리
12. 2장 이후, 다른 직업, 끝없는 탑, 도감
13. 모바일
