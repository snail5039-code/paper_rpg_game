# 필요한 도트 목록 (초안 v1)

> 관련 문서: [스토리.md](스토리.md), [성장시스템.md](성장시스템.md), [아이템시스템.md](아이템시스템.md)
> 그림체는 지금의 v4(도트 + 크레용 질감)를 그대로 쓴다.
> 이미 있는 것: 공책 마을 배경, 플레이어 걷기·공격, 하루 걷기, 슬라임, 다리, 연필심, 빨간 문(닫힘·열림), 지우개 자국, 초상화 3장, 오프닝 2장, 페이지 넘김, 키 아이콘, 연필·지우개 아이콘, 감정 말풍선, 슬라임 사라짐, 지움이 실루엣, 지우개 가루.

**각 맵에 함께 필요한 것**
- 흰 자국 버전: 2~7장 맵마다, 일부 건물·나무가 흰 자국으로 바뀐 자리 표시(따로 얹는 스프라이트로도 가능).
- 2장: 색이 있는 판과 회색 판 (색 빠짐 경계 연출용).
- 3장: 번지기 전 판과 번진 판.

## 4. 몬스터 42종 × 2가지 모습

종 목록은 [몬스터.md](몬스터.md) 2번 표와 같다. 슬라임을 뺀 41종이 필요하다.

**종마다 필요한 것**

| 그림 | 칸 수 | 내용 |
|---|---|---|
| 조금 지워진 모습 | 6칸 | 기본, 움직임 2, 공격 예고, 공격, 맞음. 한 군데가 없는 모습 |
| 많이 지워진 모습 | 6칸 | 같은 동작. 여러 군데가 없고 윤곽이 끊긴 모습 |
| 다시 그려진 모습 | 1칸 | 친구가 되는 종만. 온전한 얼굴 |
| 사라지는 연출 | 4칸 | 급하면 공통 1종으로 대신 |

**많이 지워진 모습을 쉽게 만드는 방법**
- 조금 지워진 모습의 시트를 그대로 두고, 그 위에서 **몇 군데를 더 지운 판**을 만들면 된다. 새로 그리는 게 아니라 지우는 것이라 품이 적게 든다.
- 그것도 어렵다면 코드에서 지우개 자국 무늬로 일부를 가려서 만들 수 있다. 다만 직접 지운 판이 훨씬 보기 좋다.

| 장 | 종 6가지 | 조금 지워진 곳 |
|---|---|---|
| 1 | 낙서 슬라임(있음), 삐뚤선, 점박이, 풀낙서, 모눈 거미, 지우개똥 벌레 | 얼굴 반쪽, 끝, 점 몇 개, 잎 한쪽, 다리 둘, 꼬리 |
| 2 | 회색 다람쥐, 연필밥 벌레, 가시 덩굴, 색 빠진 버섯, 나이테 달팽이, 깎다 만 부엉이 | 꼬리, 마디, 가시, 갓 무늬, 더듬이, 한쪽 날개 |
| 3 | 번진 개구리, 물감 방울, 붓털 게, 먹물 오징어, 물결 뱀장어, 얼룩 해파리 | 눈 하나, 윤곽, 집게, 다리 몇 개, 지느러미, 촉수 |
| 4 | 순찰 깡통, 덧칠 붓, 자 병정, 형광 반딧불, 압정 고슴도치, 클립 박쥐 | 얼굴 판, 손잡이, 눈금, 빛, 압정 몇 개, 귀 |
| 5 | 검은 풍선, 긁힌 목마, 티켓 나방, 솜사탕 유령, 태엽 원숭이, 꼬마전구 벌 | 끈, 다리, 날개 한쪽, 입, 심벌즈 한 짝, 침 |
| 6 | 취소선 뱀, 받침 벌레, 잉크 얼룩, 날짜 도장, 물음표 갈고리, 말줄임표 | 머리, 받침, 가장자리, 숫자, 점, 점 하나 |
| 7 | 종이 뭉치, 테이프 지네, 종이 보풀, 스테이플러 집게, 좀벌레, 접힌 종이학 | 원래 모양, 다리, 윤곽, 한쪽 날, 더듬이, 날개 |

## 6. 친구 끄적이 11종

종마다 4방향 걷기(방향당 2~4칸) + 친구 스킬 동작 2칸 + 친구들 페이지용 선 그림 1장.

콩콩이(도토리), 덩굴이, 뻐끔이(물고기), 통통(종이배), 삐뚤이(로봇), 별똥이(풍선), 뿡뿡이(범퍼카), 쉼표(올챙이), 반쪽이(강아지), 귀퉁이, 그리고 완성된 지움이.

- 말랑이는 지금 슬라임 그림에 **온전한 웃는 얼굴** 판만 추가.
- 친구들 페이지 배경 1장 (12칸짜리 빈 공책 면) + 흰 자국이 된 칸 1장.
- 종마다 "더 그려 주기"용 점선 그림 2단계.
