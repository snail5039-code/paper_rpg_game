# 공책 RPG — 게임 기획안 v2

> **업데이트:** 2026-11-21  
> **게임 제목:** 미정 (문서 내 '공책 RPG'는 임시 명칭)  
> **플랫폼:** PC (Windows 우선)  
> **장르:** 2D 탑다운 실시간 액션 RPG + 그리기/제작  
> **그래픽:** 기본 화면은 도트 그래픽, **필살기 연출에만 일러스트 사용**

> **핵심 콘셉트:** 어린 시절 공책에 그려서 놀던 게임을 실제로 플레이한다.

## 1. 게임 소개

**일본풍 도트 RPG 세계**가 담긴 공책을 탐험한다. 플레이어는 키보드와 마우스로 캐릭터를 조작해 마을과 던전을 돌아다니고, 몬스터와 **실시간으로 전투**한다. 필요한 순간에는 연필을 꺼내 **설계도를 따라 그리거나 직접 덧그려** 무기·건물·길을 제작하고 업그레이드한다.

**핵심 한 줄:** *공책 속 세계를 모험하고, 연필로 그려서 성장시키는 실시간 도트 RPG.*

### 방향성

- **비주얼:** 일본풍 아기자기한 **도트 그래픽**, 치비 캐릭터, 신사·기와지붕 마을 등
- **공책 감성:** 종이 질감, 모눈/줄공책, 연필선, 지우개 흔적, 페이지 넘김 연출
- **필살기 연출:** 발동 순간에만 **일러스트 컷인**을 사용해 전투의 특별함을 강조
- **플레이:** 실시간 탐험·전투 + 직접 그리는 제작·개조
- **입력 방식:** PC 키보드·마우스 중심 / 설계도 제작은 쉽게, 추가 낙서는 자유롭게 (**혼합형**)
- **분위기:** 따뜻하고 귀여운 일본풍 공책 RPG. 중세 서양 판타지 위주 아트는 지양

## 2. 세계관 (가안)

어느 날 발견한 공책 안에 작은 마을과 살아 움직이는 낙서들이 있다. 공책의 여러 페이지가 찢기고 지워지면서 세계가 망가지자 플레이어가 **연필과 지우개**로 마을을 복구하고, 몬스터를 물리치며 새로운 페이지를 열어 나간다.

*세계관과 스토리는 추후 변경 가능하다.*

## 3. 핵심 시스템

### 3.1 RPG 탐험 및 실시간 전투 — 확정

- **탑다운 2D 도트 RPG**, 실시간 이동·공격·회피
- 마을 → 필드 → 던전 → 보스 → 다음 페이지의 진행 구조
- NPC 대화, 퀘스트, 아이템 수집과 성장
- 일반 공격·일반 스킬은 **도트 애니메이션과 이펙트**로 표현
- **필살기는 일러스트 컷인**을 보여 준 후, 도트 게임 화면에서 효과 적용
- 전투 중 턴을 기다리지 않고 캐릭터와 적이 실시간으로 움직이고 공격

### 3.2 키보드·마우스 조작 — 확정

**키보드와 마우스를 모두 사용**하며, 아래 키 배치는 초기 제안으로 추후 조정할 수 있다.

| 동작 | 초기 조작안 |
|---|---|
| 이동 | `W`, `A`, `S`, `D` |
| 일반 공격 | 마우스 왼쪽 클릭 (전투 모드) |
| 회피 | `Space` |
| 스킬 / 필살기 | `Q`, `E`, `R` 등 (추후 확정) |
| 상호작용 | `F` |
| 그리기 모드 전환 | `Tab` (가안) |
| 선 그리기 | 마우스 왼쪽 버튼을 누르고 드래그 |
| 지우기 | 그리기 모드에서 지우개 선택 후 마우스로 드래그 |
| 메뉴 | `Esc` |

> **입력 충돌 방지:** 마우스 왼쪽 클릭은 **전투 모드에서는 공격**, **그리기 모드에서는 연필 입력**으로 동작한다.

### 3.3 연필 그리기 — 혼합형

| 모드 | 플레이 방식 | 예시 |
|---|---|---|
| 설계도 제작 | 마우스로 안내선을 따라 그리거나 빠른 제작 | 다리, 집, 검, 방패 |
| 덧그리기 개조 | 완성된 대상의 지정 영역에 선·부품 추가 | 집에 2층, 검에 장식, 방패에 보강재 |
| 자유 낙서 | 허용된 범위에서 마우스로 자유롭게 그림 | 마을 장식, 나만의 무늬 |
| 지우개 | 지정된 물체나 선을 마우스로 삭제·수정 | 장애물 제거, 잘못 그린 선 수정 |

**중요한 규칙:** 모든 그림을 AI가 자유롭게 해석하는 방식이 아니라, *설계도 종류 + 그릴 수 있는 영역 + 정해진 개조 옵션*으로 실제 게임 효과를 결정한다. 자유 낙서는 화면에 보이는 개인화 요소로 먼저 구현한다.

### 3.4 제작과 업그레이드 예시

- 강을 건너야 한다 → **다리 설계도**를 따라 그린다 → 길이 열린다.
- 허름한 여관이 있다 → **지붕·간판**을 덧그린다 → 건물이 업그레이드된다.
- 검을 획득했다 → **정해진 강화 부위**를 덧그린다 → 강화 효과가 적용된다.
- 길이 막혔다 → **지우개**로 허용된 장애물을 지운다.

※ 실제 효과는 그림의 예쁨이나 그림 실력이 아니라 게임 규칙과 재료에 의해 결정한다.

### 3.5 자원 및 성장 (초안)

- **연필심:** 건설·그리기 재료
- **지우개 가루:** 수정·삭제 재료
- **색연필/잉크:** 추후 속성·특수 효과용
- **종이조각:** 찢어진 페이지 수리 및 신규 지역 개방
- **동전:** 상점·설계도 구매

### 3.6 공책 페이지 월드

- 한 페이지 또는 펼친 면이 하나의 지역/맵
- 페이지 넘김을 지역 이동 연출로 사용
- 이미 제작·수정한 건물과 선은 저장하여 재방문 시 유지

## 5. 화면 구성 및 그래픽 규칙

| 화면 | 주요 요소 | 표현 방식 |
|---|---|---|
| 메인 게임 화면 | 일본풍 마을/필드, 플레이어, NPC, HP, 퀘스트 | 도트 그래픽 + 공책 배경 |
| 전투 화면 | 실시간 공격·회피·스킬, 적 HP | 도트 애니메이션 및 이펙트 |
| **필살기 컷인** | 필살기 발동 순간의 캐릭터 클로즈업 | **일러스트 (예외적으로 허용)** |
| 그리기 화면 | 종이 배경, 연필 커서, 설계도 안내선, 지우개, 완성 버튼 | 공책 질감 + 마우스 드로잉 |
| 제작/개조 창 | 설계도 목록, 재료, 제작 전후 미리보기 | 도트 UI |
| 가방 | 연필심, 아이템, 설계도, 장비 | 도트 UI |
| 페이지 지도 | 지역을 공책 페이지처럼 표시, 이동 및 진행도 | 도트 맵 + 페이지 연출 |

### 그래픽 원칙 — 확정

1. **캐릭터·NPC·몬스터·건물·필드·일반 전투 연출은 도트 그래픽**으로 통일한다.
2. **일러스트는 필살기 컷인 연출에만 사용**한다. 일반 대화·기본 스킬·메뉴에 일러스트를 상시 사용하지 않는다.
3. 공책 배경의 종이 질감과 연필/지우개 흔적은 **세계관 표현용 시각 효과**로 사용한다.
4. 그리기 모드에서 플레이어가 직접 그린 선은 도트 월드 위에 추가되며, 제작이 완료되면 해당 도트 오브젝트로 반영할 수 있다.

**비주얼 키워드:** `일본풍 도트 RPG` · `치비 도트 캐릭터` · `일본식 마을` · `공책 종이` · `연필선` · `모눈종이/줄공책` · `책장 넘김` · `필살기 일러스트 컷인`

## 7. MVP — 첫 플레이 가능한 버전

**목표:** 공책 속 일본풍 도트 마을을 돌아다니고, 간단한 실시간 전투를 해 본 뒤, **마우스로 다리를 그려 건너가는 플레이**를 완성한다.

### 필수 기능

1. 공책 배경의 **일본풍 도트 마을** 한 장면
2. **키보드 이동**, 충돌 처리, NPC 1명 대화
3. **실시간 기본 공격 및 몬스터 1종** (전투 방식 검증)
4. 퀘스트 1개: **끊어진 다리 복구**
5. 마우스 연필 모드: 안내선을 따라 다리 그리기
6. 완성 판정 → 다리 도트 오브젝트 생성 → 건너가기
7. 지우개/다시 그리기
8. 로컬 저장 및 불러오기

### 이후 확장

- 무기 3종, 건물 3종, 일반 스킬과 회피 고도화
- **필살기 1종 + 전용 일러스트 컷인**
- 건물 덧그리기 업그레이드
- 페이지 넘김으로 숲/던전 이동
- 보스 1마리, 자유 낙서 꾸미기

## 최우선 개발 목표

> **캐릭터가 공책 속 일본풍 도트 마을을 걷는다 → 실시간으로 몬스터를 공격한다 → 마우스로 다리를 그린다 → 다리가 실제로 생긴다 → 건너간다.**

이 흐름이 자연스럽고 재미있게 동작하면 핵심 게임성을 검증할 수 있다. **필살기 일러스트 컷인**은 이 기본 루프를 완성한 뒤 추가한다.
