# 아이템 시스템 (초안 v1)

> **상태:** 초안. 이름과 수치는 가안이다.
> 관련 문서: [스토리.md](스토리.md), [성장시스템.md](성장시스템.md), [몬스터.md](몬스터.md), [스탯.md](스탯.md), [필요한_도트.md](필요한_도트.md)
> 이 문서는 재료(파밍), 조합, 상점, 장비, 소모품, 서브 퀘스트를 정한다.

---

## 1. 전체 흐름

```text
끄적이와 싸움 ─┬─ 없앤다      → 연필심 + 재료 많이 + 동전
               └─ 다시 그려 줌 → 경험치 2배 + 지우개 가루 + 재료 조금(나눠 줌)
        ↓
재료 ─┬─ 문방구에 판다 → 동전 → 설계도·교본·소모품·기본 장비를 산다
      └─ 조합한다(설계도를 따라 그림) → 장비·소모품·윗등급 재료
        ↓
장비를 입고 다음 지역으로
```

- **동전:** 사고파는 돈.
- **연필심:** 길 그리기와 무기 강화. 없애야 나온다. (스토리: 끄적이의 선)
- **지우개 가루:** 스킬 강화와 친구 성장. 닦거나 다시 그려 주면 나온다.
- **재료:** 조합에 쓴다. 89종.

## 2. 몬스터와 재료

- 몬스터는 **42종 × 2가지 모습 = 84가지**다. 지역마다 6종씩 살고, 종마다 "조금 지워진 모습"과 "많이 지워진 모습"이 있다.
- 종마다 **흔한 재료 1개와 드문 재료 1개**를 준다. 대장 5종은 전용 재료를 하나씩 준다.
- **재료는 모두 89개**다 (42종 × 2 + 대장 5).
- 종 목록, 주는 재료, 스탯은 [몬스터.md](몬스터.md)에 있다.

## 3. 파밍

**파밍 규칙**
- 없애면 흔한 재료 1~2개. 드문 재료는 조금 지워진 모습에서 약 20%, 많이 지워진 모습에서 약 45%. 눈썰미 능력치와 가방으로 확률을 올릴 수 있다.
- 다시 그려 주면 친구가 되지 않는 경우에도(이미 그 종류의 친구가 있을 때) 고맙다며 흔한 재료 1개를 나눠 준다. 드문 재료는 **없애야만** 나온다.
- 몬스터는 페이지를 나갔다 들어오면 다시 나온다. 4장 이후로는 다시 나오는 수가 조금씩 줄어든다. (세계가 지워지고 있다.)
- 대장 재료는 한 번뿐이라, 어디에 쓸지 골라야 한다.

## 4. 조합

- **어디서:** 책갈피, 또는 문방구의 작업대.
- **방법:** 설계도를 고른다 → 재료가 맞으면 설계도의 점선이 나온다 → 따라 그린다 → 완성.
- **품질:** 얼마나 따라 그렸는지에 따라 `보통 / 꼼꼼 / 정성` 3단계. 품질이 높으면 주 스탯이 오르고 덧붙은 스탯이 0~2개 붙는다. 실패는 없다.
- **설계도 얻는 법:** 문방구에서 산다, 서브 퀘스트 보상, 상자, 대장.

| 조합 종류 | 내용 | 예 |
|---|---|---|
| **재료 합치기** | 흔한 재료 3개 → 윗지역 재료와 맞바꾸거나, 같은 지역 드문 재료 1개 | 삐뚤선 토막 3 → 곧은 선 1 |
| **색 만들기** | 색 재료 2개 → 새 색 | 파란 물감 + 초록 색연필심 → 청록 물감 |
| **소모품 만들기** | 재료 2~3개 → 소모품 | 말랑 조각 2 + 풀잎 낙서 1 → 말랑 반창고 |
| **장비 만들기** | 재료 3~5개 + 설계도 → 장비 | 회색 털 4 + 덩굴 선 2 → 스케치 털모자 |
| **장비 올리기** | 같은 장비 + 윗등급 재료 → 한 등급 위 | 스케치 털모자 + 붓털 3 → 색칠 털모자 |
| **섞어 보기** | 설계도 없이 재료 2개를 섞어 본다. 맞으면 새 설계도를 알게 된다 | 숨은 조합 20개 |

## 5. 상점 (문방구)

- 마을마다 **문방구 할아버지**가 있다. 말을 걸면 사기, 팔기, 작업대 중에서 고른다.
- **사기:** 그 지역 등급의 기본 장비, 소모품, 설계도, 스킬 교본.
- **팔기:** 재료와 장비를 동전으로 바꾼다. 재료마다 값이 다르고 드문 재료가 비싸다.
- **진열:** 장을 넘길 때마다 물건이 바뀐다. 5장부터는 진열대가 비어 가고, 7장의 가게에는 아무도 없다. 장부 옆에 동전을 두고 가져가는 무인 판매가 된다.
- **할아버지의 저울:** 연필심도 사고판다. 4장 이후에는 연필심을 팔 때 할아버지가 한마디씩 한다.

| 그 밖의 가게 | 있는 곳 | 파는 것 |
|---|---|---|
| **귀퉁이 장터** | 페이지 귀퉁이를 접으면 나오는 숨은 가게. 2·4·6장 | 드문 재료, 숨은 설계도. 값이 비싸다 |
| **스티커 뽑기** | 5장 놀이동산 | 동전을 넣으면 악세사리가 무작위로 나온다 |

## 6. 장비

### 부위 6곳

| 부위 | 주 스탯 |
|---|---|
| **도구 (무기)** | 공격 |
| **모자** | 최대 HP |
| **옷** | 방어 |
| **신발** | 이동 속도 |
| **가방** | 드문 재료 확률 |
| **악세사리** (2칸) | 모양마다 다름 |

장비마다 주 스탯, 모양 특성, 덧붙은 스탯(조합 품질에 따라 0~2개)이 있다. 수치와 모양별 특성 60가지는 [스탯.md](스탯.md)에 있다.

### 부위마다 50개 = 모양 10가지 × 등급 5단계

| 등급 | 색 | 쓰이는 재료 | 대략 얻는 때 |
|---|---|---|---|
| **낙서** | 회색 연필선 | 1장 재료 | 1~2장 |
| **스케치** | 진한 연필선 | 2장 재료 | 2~3장 |
| **색칠** | 물감색 | 3장 재료 | 3~4장 |
| **덧칠** | 사인펜 굵은 선 | 4~5장 재료 | 4~6장 |
| **완성** | 크레파스 알록달록 | 6~7장 재료 + 대장 재료 | 6~7장 |

같은 모양이라도 등급이 오르면 선이 또렷해지고 색이 채워진다. 낙서 등급은 선만 있는 그림이고, 완성 등급은 다 칠한 그림이다.

| 부위 | 모양 10가지 |
|---|---|
| **도구** | 연필, 몽당연필, 샤프, 깃펜 (빠른 계열) / 붓, 납작붓, 분필 (넓은 계열) / 사인펜, 형광펜, 크레용 (강한 계열) |
| **모자** | 종이 모자, 신문지 투구, 야구 모자, 털모자, 밀짚모자, 색종이 왕관, 머리띠, 고깔모자, 안전모, 베레모 |
| **옷** | 후드티, 체육복, 우비, 미술 앞치마, 멜빵바지, 잠옷, 교복, 보자기 망토, 조끼, 스웨터 |
| **신발** | 운동화, 장화, 슬리퍼, 실내화, 샌들, 롤러스케이트, 털신, 구두, 고무신, 축구화 |
| **가방** | 책가방, 실내화 주머니, 큰 필통, 도시락 가방, 크로스백, 종이봉투, 보자기, 화구 가방, 허리 가방, 바구니 |
| **악세사리** | 머리끈, 이름표, 배지, 목도리, 손목시계, 안경, 반창고, 열쇠고리, 스티커, 팔찌 |

합계 6부위 × 50 = **300개**.

### 모양마다 다른 성격

- 등급은 수치를 올리고, **모양은 성격을 정한다.** 예를 들어 장화는 번진 바닥에서 안 미끄러지고, 롤러스케이트는 빠르지만 멈추기 어렵다. 우비는 물감·먹물 피해를 줄이고, 미술 앞치마는 그리기 판정을 너그럽게 한다.
- 그래서 높은 등급만 입는 게 아니라, 지역에 맞는 모양을 고르게 된다.

### 세트 5가지

같은 이름으로 3부위 이상 맞추면 효과가 붙는다.

| 세트 | 부위 | 효과 |
|---|---|---|
| **체육 시간** | 체육복, 운동화, 야구 모자 | 회피 간격이 줄어듦 |
| **비 오는 날** | 우비, 장화, 책가방 | 물·먹물 지형에서 느려지지 않음 |
| **미술 시간** | 미술 앞치마, 베레모, 화구 가방 | 그리기 판정이 너그러워지고 조합 품질이 오름 |
| **소풍** | 밀짚모자, 도시락 가방, 샌들 | 소모품 효과가 커짐 |
| **잠자리** | 잠옷, 털신, 고깔모자 | 책갈피에서 쉬면 한동안 HP가 조금씩 회복됨 |

### 얻는 길

| 길 | 비중 |
|---|---|
| 조합 | 가장 많음 |
| 문방구 | 그 지역의 기본 등급 |
| 몬스터가 드물게 떨어뜨림 | 조금 |
| 서브 퀘스트 보상, 상자 | 특별한 모양 |
| 스티커 뽑기 | 악세사리 |

### 화면에 보이는가

장비는 **아이콘과 장비 창에서만** 보이고, 걷는 캐릭터 그림은 바뀌지 않는다. 300개를 걷는 그림에 다 입히면 그림이 수천 장 필요하다. 예외로 **모자만** 캐릭터 머리 위에 얹어 보이게 하는 것은 가능하다(모양 10가지 × 방향 4개).

## 8. 서브 퀘스트 24개

장마다 3~4개. 주민에게 말을 걸면 받는다. 하지 않아도 끝까지 갈 수 있다.

| 종류 | 내용 |
|---|---|
| **부탁** | 지워진 물건을 다시 그려 준다 |
| **모으기** | 재료를 모아다 준다 |
| **찾기** | 잃어버린 것, 숨은 끄적이를 찾는다 |
| **잡기** | 특정 몬스터를 몇 마리 쓰러뜨린다 (없애든 다시 그리든) |
| **전하기** | 다른 주민에게 물건이나 말을 전한다 |
| **내기** | 귀퉁이와의 작은 내기 |

| 장 | 퀘스트 | 내용 | 보상 |
|---|---|---|---|
| 1 | 간판이 없어요 | 가게 간판을 다시 그려 준다 | 낙서 종이 모자 |
| 1 | 풀밭 청소 | 삐뚤선 5마리 | 동전, 설계도 |
| 1 | 이름이 뭐였더라 | `□□이` 주민의 이름표 조각을 찾아 준다. 세 글자 중 두 글자만 찾을 수 있다 | 이름표 (악세사리) |
| 2 | 도토리 저금 | 도토리 깍지 6개 | 스케치 책가방 |
| 2 | 색을 돌려줘 | 회색이 된 꽃밭을 색연필로 칠해 준다 | 초록 색연필심, 경험치 |
| 2 | 같은 말만 하는 아이 | 문장이 짧아지는 주민에게 매일 말을 걸어 준다. 장이 끝나면 더는 대답하지 않는다 | 마지막에 남긴 한 글자 (악세사리) |
| 2 | 귀퉁이의 내기 1 | 누가 먼저 버섯 3개를 따나 | 숨은 설계도 |
| 3 | 우리 집이 어디죠 | 번져서 집을 못 찾는 주민을 데려다준다 | 색칠 장화 |
| 3 | 여관 고치기 | 지붕과 간판을 덧그린다 | 여관에서 무료로 쉬기 |
| 3 | 옆자리 | 뻐끔이의 짝을 찾아 호수를 뒤진다. 찾는 것은 흰 자국이다 | 뻐끔이의 정 +1 |
| 3 | 먹물 닦기 | 먹물 오징어 6마리 | 우비 설계도 |
| 4 | 통행증 | 도시 문지기에게 줄 서류를 모아 온다 | 도시 안쪽 출입 |
| 4 | 덧칠 아래 | 검게 칠해진 사람 모양 앞에 꽃을 놓아 달라는 부탁 | 덧칠 조각, 경험치 |

| 4 | 귀퉁이의 내기 2 | 순찰 깡통에게 안 들키고 광장 건너기 | 귀퉁이 장터 할인 |
| 5 | 표 받는 사람 | 매표소 끄적이에게 티켓 반쪽 8개를 모아다 준다. 손님은 오지 않는다 | 덧칠 크로스백 |

| 7 | 다음은 뭐였어 | 그리다 만 끄적이 셋을 끝까지 그려 준다. 연필이 닳는다 | 반쪽이의 정 +1 |
| 7 | 붙여 줘 | 찢어진 종이 두 장을 테이프로 이어 준다 | 완성 보자기 망토 |
| 7 | 주인 없는 장부 | 빈 문방구의 장부를 끝까지 읽는다 | 문방구 할아버지의 저울 (악세사리) |

## 9. 가방과 화면

- **가방 창:** 재료 / 소모품 / 장비 / 설계도 / 중요한 물건 5칸.
- **장비 창:** 캐릭터 그림과 6부위 칸, 세트 표시, 오른 수치.
- **조합 창:** 설계도 목록 → 필요한 재료 → 따라 그리기.
- **상점 창:** 사기 / 팔기 / 작업대.
- **퀘스트 창:** 큰 줄기와 서브 퀘스트 목록.
- 빨리 쓰는 소모품 칸 4개 (숫자 1~4).

## 10. 이야기와 맞물리는 지점

- **4장 이후:** 드문 재료는 없애야만 나온다. 좋은 장비를 입은 플레이어는 그만큼 많이 없앤 플레이어다. 장비 설명 맨 아래에 작게 적힌다. `만드는 데 든 것: 누군가 N`.
- **7장:** 말랑 조각으로 만든 장비를 입고 있으면, 말랑이가 지워진 뒤 그 장비의 이름이 흐려진다.
- **8장:** 가방이 비어 있다. 열 살에게는 지우개뿐이다.
- **9장:** 화면이 지워질 때 빠른 칸의 소모품 아이콘도 지워진다.

## 11. 아직 정하지 않은 것

- 수치 전부 (값, 확률, 능력치)
- 숨은 조합 20개의 내용
- 300개 장비의 개별 이름과 수치 표 (모양 × 등급 규칙으로 자동 생성할지, 일부는 손으로 정할지)
- 가방 칸 수 제한을 둘지
