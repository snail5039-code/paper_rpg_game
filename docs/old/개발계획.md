# 개발 계획 (간단 버전)

> 기준 문서: [기획안 v2](기획안_v2.md)

## 목표

**걷기 → 몬스터 공격 → 마우스로 다리 그리기 → 다리 생성 → 건너가기**

이 한 바퀴가 돌아가면 MVP 완성. 필살기 컷인·건물 개조·보스는 그 다음.

## 마일스톤

| # | 기간(예상) | 작업 | 완료 기준 |
|---|---|---|---|
| M1 | 1주 | Godot 프로젝트 + 공책 배경 + 마을 타일맵 | 창에 마을 맵이 보임 |
| M2 | 1주 | 플레이어 WASD 이동 + 충돌 + NPC 1명 대화(F) | 벽 통과 안 함, 대화창 뜸 |
| M3 | 1주 | 실시간 기본 공격(좌클릭) + 몬스터 1종 | 몬스터 HP 감소·처치 |
| M4 | 1주 | 그리기 모드(Tab) + Line2D 선 그리기 + 지우개 | 마우스로 선이 그려지고 지워짐 |
| M5 | 1주 | 다리 설계도 판정 (안내선 근접도 체크) | 안내선을 따라 그리면 성공 |
| M6 | 3일 | 다리 오브젝트 생성 + 통행 가능 처리 | 강을 건너감 |
| M7 | 3일 | user:// 저장/불러오기 | 재실행 후 다리·퀘스트 유지 |

## 설계 메모

- **입력 모드 분리:** `GameMode { COMBAT, DRAW }` 하나로 좌클릭 의미를 전환
- **설계도 판정:** 안내선 위 샘플 포인트들 중 플레이어 선과 일정 거리(예: 12px) 이내인 비율 ≥ 80% → 성공
- **데이터:** 설계도는 `data/blueprints/*.tres` (안내선 포인트, 필요 재료, 결과 씬)
- **타일:** 16×16 도트 기준, 화면 320×180 → 정수 배율 확대 (잠정)
